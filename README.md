# 知微个人博客

一个纯静态中文个人博客，无数据库、无服务器依赖。支持文章封面、正文图片、分类筛选、移动端阅读和 Markdown 写作预览。

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。

## 发布新文章

1. 上线后打开 `/admin/`，使用 GitHub 登录。
2. 进入“文章”并点击“新建文章”，填写标题、摘要、分类和正文，可直接上传封面与正文图片。
3. 保存为草稿、送审或点击发布。发布后 GitHub Pages 会自动构建上线。

本地仍可使用 `/editor.html` 快速写作和预览。

图片建议放在 `assets/images/`，文件名使用英文和短横线。封面建议尺寸 1600 × 1000，单张不超过 500 KB。

## 上线

这是标准静态站点，可直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。构建命令留空，发布目录填 `/`。
